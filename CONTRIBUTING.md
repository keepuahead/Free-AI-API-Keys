# Contributing to Free AI APIs Key

Thank you for your interest in contributing! This repository helps developers discover affordable AI API access.

## 🤝 Ways to Contribute

### 1. 🐛 Report Issues
- Found a bug in our examples? [Open an issue](../../issues)
- Documentation unclear? Let us know
- Tool compatibility problem? Report it

### 2. 💡 Suggest Improvements
- New integration examples
- Additional programming languages
- Better cost comparison tools
- Documentation improvements

### 3. 🔧 Submit Code
- Add new code examples
- Create migration scripts
- Build comparison tools
- Improve existing examples

### 4. 📖 Improve Documentation
- Fix typos
- Clarify instructions
- Add screenshots
- Translate content

### 5. 🌟 Spread the Word
- Star this repository
- Share with fellow developers
- Write about your experience
- Help others in Discord

## 📝 Contribution Guidelines

### Code Examples
- Keep it simple and well-commented
- Include error handling
- Add requirements.txt or package.json
- Test your code before submitting

### Documentation
- Use clear, concise language
- Include code snippets where helpful
- Add screenshots for UI tools
- Check spelling and grammar

### Tools & Scripts
- Include README with usage instructions
- Add command-line help
- Handle edge cases gracefully
- Comment complex logic

## 🚀 Getting Started

1. **Fork the repository**
2. **Clone your fork**
   ```bash
   git clone https://github.com/YOUR_USERNAME/Free-AI-APIs-Key.git
   cd Free-AI-APIs-Key
   ```
3. **Create a branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes**
5. **Test thoroughly**
6. **Commit with clear messages**
   ```bash
   git commit -m "Add: Python streaming example"
   ```
7. **Push to your fork**
   ```bash
   git push origin feature/your-feature-name
   ```
8. **Open a Pull Request**

## 📋 Pull Request Process

1. **Describe your changes** clearly in the PR description
2. **Link any related issues**
3. **Ensure documentation is updated**
4. **Test your changes**
5. **Wait for review** - we'll respond within 48 hours

## 🏷️ Commit Message Format

Use clear, descriptive commit messages:

- `Add: New Python example for function calling`
- `Fix: Correct base URL in JavaScript example`
- `Update: Improve cost calculator accuracy`
- `Docs: Add n8n integration guide`
- `Refactor: Simplify migration script`

## 🎨 Code Style

### Python
- Follow PEP 8
- Use type hints where appropriate
- Include docstrings

### JavaScript/TypeScript
- Use ESLint configuration
- Prefer async/await
- Include JSDoc comments

### Documentation
- Use Markdown
- Keep line length reasonable
- Use code blocks with language tags
